# Auto Steam Account (Dim4n4ik Shop) — подробная инструкция

Плагин **Auto Steam Account (Dim4n4ik Shop)** предназначен для автоматической продажи цифровых товаров на FunPay через Cardinal.

На данный момент плагин поддерживает:

- автоматическую покупку и выдачу Steam-аккаунтов через API **dim4n4ik.shop**;
- выдачу Steam-аккаунтов из собственной заранее пополненной базы;
- продажу почт **Hotmail / Outlook** из отдельных локальных баз;
- автоматическое управление остатками и автовыдачей FunPay;
- уведомления о заказах, ошибках и остатках;
- статистику продаж;
- резервные копии настроек и баз;
- обновление плагина через GitHub или локальный файл.

> Инструкция актуальна для версии **1.0.2**.

---

## Что нужно знать перед установкой

Плагин работает с двумя основными типами товара.

### Steam-аккаунты

Steam-аккаунты можно продавать двумя способами:

1. **Покупать при заказе** — после оплаты заказа на FunPay плагин автоматически покупает нужный аккаунт через API dim4n4ik.shop и отправляет его покупателю.
2. **Выдавать из базы данных** — вы заранее добавляете аккаунты в локальную базу, а после покупки плагин берет нужное количество из этой базы.

### Почты Hotmail / Outlook

Почты **не покупаются через API dim4n4ik.shop**.

Для почтового лота создается отдельная база, которую вы пополняете самостоятельно:

- текстом;
- файлом `.txt`;
- файлом `.csv`.

Каждая строка считается отдельным товаром.

Например:

```text
mail1@outlook.com:password
mail2@hotmail.com:password
mail3@outlook.com:password
```

Почтовая база закрепляется за конкретным LOT ID, поэтому почты разных лотов не смешиваются.

## 1. Скачайте файл плагина

Скачайте актуальный `.py` файл из репозитория:

```text
/restart
```

После перезапуска плагин появится в списке плагинов.

Также открыть его меню можно командой:

```text
/d4shop
```

# Настройка API dim4n4ik.shop

API нужен для автоматической покупки Steam-аккаунтов и для пополнения Steam-баз через магазин.

Для почтовых баз API не требуется.

## Где получить API-ключ

Откройте:

https://t.me/dim4n4ikshop_bot

Далее перейдите:

**Профиль → 🔑 API**

Скопируйте выданный API-ключ.

Обычно ключ начинается с:

```text
rk_
```

## Как добавить API-ключ в плагин

Откройте:

**Настройки → 🏪 Аккаунт dim4n4ik.shop → 🔑 Добавить API-ключ**

Отправьте ключ боту.

После сохранения плагин попробует проверить API и получить текущий баланс.

В этом же разделе можно:

- изменить API-ключ;
- удалить API-ключ;
- выполнить проверку API;
- посмотреть баланс.

> Если вы продаете только почты из локальных баз, API-ключ для этого не нужен.

# Настройки плагина

Откройте:

**Настройки → ⚙️ Настройки плагина**

В этом разделе находятся основные параметры.

## Состояние плагина

Позволяет полностью включить или выключить обработку новых заказов.

При выключенном плагине новые заказы не обрабатываются, а автоматическое управление остатками останавливается.

Уже запущенная выдача при этом не прерывается.

## Заказы

Здесь находятся:

- автоматический возврат денег;
- автоматическое выключение лотов при отсутствии товара;
- сообщения покупателю.

### Автовозврат

Если функция включена и плагин не может выдать товар по поддерживаемой причине, он может автоматически выполнить возврат заказа.

Если вы хотите самостоятельно контролировать проблемные заказы, оставьте автовозврат выключенным.

### Автодеактивация

При отсутствии товара плагин может автоматически выключить соответствующий лот на FunPay.

Когда товар снова появляется, плагин может вернуть лот в работу.

### Сообщения покупателю

Можно изменить стандартные сообщения без редактирования кода плагина.

Доступны шаблоны:

- оплата получена;
- заголовок выдачи;
- сообщение после выдачи;
- сообщение при возврате;
- сообщение при задержке или ручной проверке.

Поддерживаемые переменные:

```text
{order_id}
{order_url}
{product_title}
{qty}
{reason}
```

# Безопасность

Откройте:

**Настройки плагина → 🛡 Безопасность**

## Защита от убытка

Если защита включена, перед автоматической покупкой через API плагин сравнивает цену продажи на FunPay со стоимостью закупки.

Если продажа оказывается ниже допустимого уровня, автоматическая закупка блокируется.

## Минимальная маржа

Можно задать дополнительный процент поверх закупочной стоимости.

Например, если поставить:

```text
20
```

плагин будет учитывать минимальную маржу в 20%.

> Эта функция относится к товарам, которые покупаются через API. Для товара из локальной базы новой закупки во время заказа нет.

# Базы аккаунтов и почт

Откройте:

**Настройки плагина → 🗃 Базы аккаунтов**

В этом разделе хранятся локальные товары.

Плагин поддерживает два типа баз:

- Steam-базы;
- почтовые базы Hotmail / Outlook.

---

## Steam-база

Steam-базу можно создать вручную.

Нажмите:

**➕ Создать базу**

Далее:

1. Введите название базы.
2. Выберите товар dim4n4ik.shop из каталога.
3. После создания откройте базу.

Steam-базу можно пополнять тремя способами.

### Купить через dim4n4ik.shop

Нажмите:

**🛒 Купить через dim4n4ik.shop**

Введите количество.

Плагин купит товар через API и автоматически положит полученные данные в базу.

### Добавить текстом

Нажмите:

**📝 Добавить текстом**

Каждая непустая строка будет отдельным товаром.

### Загрузить файлом

Нажмите:

**📎 Загрузить файлом**

Поддерживаются:

```text
.txt
.csv
```

Каждая непустая строка файла считается отдельной позицией.

Повторяющиеся значения пропускаются.

---

## Почтовая база Hotmail / Outlook

Для почты отдельную базу вручную создавать обычно не требуется.

Она автоматически создается при ручном добавлении почтового LOT ID.

Почтовая база:

- закреплена за своим лотом;
- не имеет товара dim4n4ik.shop;
- не использует API;
- не может пополняться кнопкой покупки через dim4n4ik.shop.

Доступны только:

- **📝 Добавить текстом**
- **📎 Загрузить файлом**

Это сделано специально, потому что почты Hotmail / Outlook отсутствуют в используемом API магазина.

---

## Просмотр базы

В карточке базы отображаются:

- количество доступного товара;
- количество товара в резерве;
- сколько всего добавлено;
- сколько продано;
- сколько лотов используют базу.

Через кнопку **👁 Просмотреть аккаунты** можно посмотреть содержимое базы.

Также доступные позиции можно экспортировать в `.txt`.

> Файлы с аккаунтами и почтами содержат реальные данные товара. Не отправляйте их посторонним.

## Где найти LOT ID

В ссылке будет его ID.

Например:

```text
https://funpay.com/lots/offer?id=12345678
```

LOT ID:

```text
12345678
```

В плагин можно отправить как сам ID, так и ссылку на лот.

## Ручное добавление Steam-лота

Нажмите:

**➕ Добавить LOT ID**

Отправьте LOT ID.

После проверки плагин спросит тип товара:

- **🎮 Steam аккаунт**
- **📧 Почты Hotmail / Outlook**

Выберите:

**🎮 Steam аккаунт**

После этого появится выбор режима выдачи.

---

# Режим 1 — покупать Steam-аккаунт при заказе

Выберите:

**🌐 Покупать при заказе**

После этого выберите нужный товар из каталога dim4n4ik.shop.

Теперь схема работы будет такой:

1. Покупатель оплачивает заказ на FunPay.
2. Плагин определяет нужный лот.
3. Проверяет доступность товара.
4. Покупает необходимое количество через API.
5. Получает текстовые данные аккаунта.
6. Отправляет товар покупателю в чат FunPay.
7. Обновляет статистику и остатки.

Для этого режима на балансе dim4n4ik.shop должно быть достаточно средств.

---

# Режим 2 — выдавать Steam-аккаунты из базы

При настройке Steam-лота выберите:

**🗃 Выдавать из базы данных**

Далее выберите созданную Steam-базу.

Теперь при новом заказе плагин не будет покупать аккаунт через API.

Он возьмет нужную позицию из выбранной базы и отправит ее покупателю.

Этот режим удобен, если вы:

- закупаете аккаунты заранее;
- хотите сами контролировать запас;
- импортируете собственные аккаунты;
- хотите уменьшить зависимость от наличия товара в магазине в момент заказа.

---

# Добавление почтового лота Hotmail / Outlook

Для почтового лота используйте именно **ручное добавление LOT ID**.

Откройте:

**Настройки → 🔗 Настройки лотов → ➕ Добавить LOT ID**

Отправьте ID или ссылку на почтовый лот.

После проверки выберите:

**📧 Почты Hotmail / Outlook**

Плагин автоматически:

1. создаст отдельную почтовую базу;
2. закрепит ее за этим LOT ID;
3. переключит лот на выдачу только из этой базы;
4. откроет созданную базу.

После этого добавьте почты через:

**📝 Добавить текстом**

или

**📎 Загрузить файлом**

После пополнения база готова к автоматической выдаче.

## Как работает продажа почты

Пример.

В базе находится:

```text
mail1@outlook.com:pass1
mail2@hotmail.com:pass2
mail3@outlook.com:pass3
```

Покупатель оплачивает одну единицу товара.

Плагин берет одну доступную строку из базы и отправляет ее покупателю.

После успешной выдачи позиция считается проданной.

# Количество за покупку

Параметр:

**🔢 Количество за покупку**

определяет, сколько строк товара надо выдать за одну единицу заказа на FunPay.

Например:

```text
1
```

Одна покупка на FunPay = один аккаунт или одна почта.

Если указать:

```text
3
```

одна единица заказа = три позиции из источника.

---

# Количество в автовыдаче FunPay

Параметр:

**⚡ Кол-во в автовыдаче**

управляет количеством позиций, которое плагин будет держать в мгновенной выдаче FunPay.

Допустимое значение:

```text
0–500
```

Если поставить `0`, автоматическая работа с заглушками автовыдачи для этого лота будет отключена.

Если указать значение больше нуля, плагин будет синхронизировать доступное количество с реальным остатком источника.

# Включение и выключение лота

В карточке лота есть кнопка состояния:

```text
🟢 Лот: ВКЛ
```

или

```text
🔴 Лот: ВЫКЛ
```

Она позволяет включать и выключать лот непосредственно с панели плагина.

# Удаление лота

Плагин предлагает два варианта.

## Только из плагина

Лот останется на FunPay, но плагин больше не будет его обрабатывать.

При таком удалении автоматическая выдача FunPay для лота отключается.

## С FunPay и из плагина

Лот удаляется с FunPay вместе с его настройкой в плагине.

> Удаление самого лота с FunPay необратимо.

# Уведомления

Откройте:

**Настройки плагина → 🔔 Уведомления**

Можно отдельно включить или выключить:

- **🛒 Пришёл заказ** — новый оплаченный заказ;
- **✅ Заказ выдан** — товар успешно отправлен;
- **❌ Заказ не выдан** — выдача завершилась ошибкой;
- **⚠️ Ошибки** — внутренние ошибки работы плагина;
- **💰 Низкий баланс** — баланс API опустился ниже установленного порога;
- **📦 Нет товара / сток** — источник товара закончился.

Также можно изменить:

- порог низкого баланса;
- интервал проверки баланса.

При восстановлении баланса или товара плагин также может отправить соответствующее уведомление.

---

# Что происходит, если товар закончился

Для Steam-лота в режиме API плагин проверяет остаток dim4n4ik.shop.

Для Steam-базы и почтовой базы проверяется локальный остаток.

Если источник пустой, в зависимости от настроек плагин может:

- уведомить администратора;
- отключить лот;
- убрать позиции из автовыдачи FunPay.

После появления товара лот может снова вернуться в работу.

---

# Что происходит при проблеме с выдачей

Плагин старается не допускать двойной продажи одного товара.

Если аккаунт или почта уже были зарезервированы из базы, но FunPay не подтвердил полную отправку, заказ может перейти в ручную проверку.

Администратор получает кнопки для принятия решения.

Перед возвратом товара обратно в базу обязательно проверьте чат покупателя и убедитесь, что товар действительно не был отправлен.

# Как удалить плагин

Откройте главную страницу:

**Auto Steam Account (Dim4n4ik Shop)**

Нажмите:

**🗑 Удалить**

После подтверждения удаляются:

- файл плагина;
- настройки;
- базы аккаунтов;
- базы почт;
- статистика;
- логи;
- резервные копии внутри папки плагина.

> Удаление данных необратимо. Если они вам нужны, сначала экспортируйте резервную копию.

После удаления выполните:

```text
/restart
```

# Быстрая настройка Steam через API

Если нужна самая простая схема:

1. Установите плагин.
2. Выполните `/restart`.
3. Добавьте API-ключ dim4n4ik.shop.
4. Создайте лот на FunPay.
5. Откройте **Настройки лотов**.
6. Добавьте или выберите LOT ID.
7. Выберите **Steam аккаунт**.
8. Выберите **Покупать при заказе**.
9. Выберите товар dim4n4ik.shop.
10. Проверьте количество за покупку и автовыдачу.
11. Готово.

# Быстрая настройка Steam через локальную базу

1. Создайте Steam-базу.
2. Выберите товар, которому соответствует база.
3. Добавьте аккаунты текстом, файлом или купите их через dim4n4ik.shop.
4. Добавьте Steam-лот.
5. Выберите режим **Выдавать из базы данных**.
6. Выберите созданную базу.
7. Проверьте остаток.
8. Готово.

---

# Быстрая настройка Hotmail / Outlook

1. Создайте почтовый лот на FunPay.
2. Откройте **Настройки лотов**.
3. Нажмите **➕ Добавить LOT ID**.
4. Отправьте ID почтового лота.
5. Выберите **📧 Почты Hotmail / Outlook**.
6. Плагин автоматически создаст отдельную базу.
7. Добавьте почты текстом или `.txt/.csv` файлом.
8. Проверьте остаток.
9. Готово.
